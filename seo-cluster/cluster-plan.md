## Interne Link Matrix (samenvatting)

### Verplichte links (pillar ↔ spoke)
Elke spoke linkt naar zijn pillar met het pillar-keyword als anchor.
Elke pillar linkt naar al zijn spokes.

### Spoke-naar-spoke (binnen cluster, 2-3 per post)

**Cluster 1 (Gazon):**
- Accu grasmaaier ↔ Robotmaaier
- Robotmaaier ↔ Hoe kies je een robotmaaier
- Hoe kies je robotmaaier ↔ Robotmaaier zonder grensdraad

**Cluster 2 (BBQ):**
- Kamado bbq ↔ Kamado vs Weber
- Rookloze vuurkorf ↔ Vuurkorf tips
- Hoe kies je kamado ↔ Kamado vs Weber

**Cluster 3 (Ontspanning):**
- Loungeset ↔ Hoe kies je loungeset
- Jacuzzi ↔ Opblaasbaar vs vast
- Zweefparasol ↔ Loungeset (sfeer/tuin context)

**Cluster 4 (Tech):**
- Solar verlichting ↔ Hoe werkt solar
- Solar verlichting ↔ Solar plaatsen
- Buitenspot ↔ Solar verlichting

**Cluster 5 (Robot stofzuiger):**
- Pillar ↔ Dweilfunctie
- Pillar ↔ Voor huisdieren
- Hoe kies je ↔ Budget robot stofzuiger

### Cross-cluster links (1 per post, strategisch)
- Cluster 1 pillar → Cluster 4 (slimme tuin) [tuin tech angle]
- Cluster 2 pillar → Cluster 3 (loungeset, sfeervolle tuin)
- Cluster 4 pillar → Cluster 1 (robotmaaier als slimme tuin gadget)
